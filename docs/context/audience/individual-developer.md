# Reader persona: Individual developer

| Field | Value |
|---|---|
| **Group** | outside this repository, adopts what it produces |
| **Actor type** | human |
| **Primary goal** | Have agents follow their own rules in every session, with little setup. |

## What this reader needs

- How the built-in pack and a project's own choices combine, without an org pack in between.
- The few commands and files that change which guidance an agent receives.
- Plain answers to "what is active for this step, and why".

## What frustrates them

- Governance set up for teams that they must work around as one person.
- Having to read schemas to change one rule.

## Signal that the documentation served them

They can switch a rule on or off for one project and see the agent act on it.
