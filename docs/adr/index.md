# Decision records

This section is the home for the charter offering module's **architecture
decision records (ADRs)**. Following the Spec Kitty common-docs convention,
ADRs are filed by era under `adr/<era>/` (for example `adr/4.x/`) and carry
MADR-style frontmatter so a docsite can index them. Living architectural design
stays under [Architecture](../architecture/index.md); this section holds the
immutable record of decisions only.
