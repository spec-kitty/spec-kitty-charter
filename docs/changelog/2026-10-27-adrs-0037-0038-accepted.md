# 2026-10-27 — ADR-0037 and ADR-0038 are accepted

**Both records were proposed earlier today and are now accepted** by the operator, Stijn Dejongh.
[ADR-0036](/adr/0036-round-trip-fidelity-is-equality-of-meaning/) was accepted earlier the same day
with the charter's amended round-trip promise.

- [ADR-0037](/adr/0037-kind-keyed-pack-registry-and-whole-pack-seam/): the `Pack` aggregate and
  pack storage key their artifacts by kind, and a whole pack loads from and writes to a directory.
  It supersedes in part step 3 of [ADR-0024](/adr/0024-doctrine-artifact-family-contract/)'s
  amendment of 2026-10-26.
- [ADR-0038](/adr/0038-one-configuration-root-a-directory-per-domain/): the service keeps its files
  under one configuration root, a directory per domain. It supersedes in part
  [ADR-0011](/adr/0011-seam-runtime-fail-closed-daemon-and-freshness/) and decision 11 of
  [ADR-0018](/adr/0018-action-context-read-and-seam-access-surface/): a missing pack directory is
  no longer refused, it is simply not served.

The [ADR index](/adr/) records the new statuses, and the superseded records carry the pointer.
No code changes.
