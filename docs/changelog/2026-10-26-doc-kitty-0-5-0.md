# 2026-10-26 — The docsite moves to doc-kitty 0.5.0

The site is built with `@spec-kitty/doc-toolkit` `0.5.0` instead of `0.4.0`. Astro 7,
Starlight 0.42 and Node 22.22 stay as they were.

## What changed

- **`kind` is required on every page again.** `npm run validate` now fails a page without
  `kind`, the root `docs/README.md` included. Every page already carries one, and the Python
  docs checks required it already.
- **The OKF export works under the site's base path.** Links in the exported bundle resolve
  against `/spec-kitty-charter/`, and a section `README` with body text is exported as a page
  too, so its prose reaches agents. `okf_version` stays `0.2`.
- **Reading fixes.** The table of contents rail no longer jumps on a slow first paint, and
  above 1920px the sidebar tint reaches the screen edge.
- **The generated glossary pages carry the new generator stamp**
  (`doc-kitty-glossary/0.5.0`). Their terms are unchanged.

## Who is affected

Contributors: give every new page a `kind`, as the page template already does. Nothing else
changes in how you write docs. The upgrade steps are in
[Building the docsite](/guides/docsite/).
