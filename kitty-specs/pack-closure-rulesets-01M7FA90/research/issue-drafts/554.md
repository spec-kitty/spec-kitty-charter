## Title

ADR-0075 slice 5: the pack rules on the kernel vocabulary, one reader, and the validation edge

## Body

Part of #549 (ADR-0075, decisions 3, 4, 5 and 7, as amended on 2026-11-16). Size L.

- **The consistency rules live in the packs domain** (`packs.domain.rules`): one kernel ruleset per pack file kind
  (graph, endpoint, mission type, step, artifact, asset, fragment, prompt slot), composed into
  `PackRulesets.content()`; `CLOSURE` (`PackRulesets.closure()`) judges the composition facts of a set of packs with
  levels (cycle, unknown and out-of-range dependency, parent, level, name, duplicate id, sibling and preset conflicts)
  and reports every fault, the offering keeping its first refusal. No judging port.
- **One reader, in the storage edge (S1, S3).** `FileSystemPackInspector` walks a pack tree once into one `TreeRead`
  (the `PackContents`, a `TreeCensus` of the files held and not held, and the read faults, the S2 format prechecks
  among them). The storage rules and `StorageCodes` live in `packs.infra.storage.rules`, named by nothing outside
  `packs.infra.storage` and `deployable`. `PackAssembly` builds the aggregate from the same read; the second read and
  its fail-closed guard go. The compose read runs the store half only (`StoreRead`, S7).
- **One domain port of the read (S6).** `PackReading` (`PackReadout read(PackRoot)`) replaces `PackInspector`; its
  readout carries the storage edge's verdict, `StorageRulesets.verdict` (the read faults, `registration() =
  holding().must(content().on(TreeRead::contents))`, then the manifest membership when those pass). No ArchUnit rule
  is widened.
- **Registration** (`packs.application`) judges the readout and refuses through `PackRefusals` before assembly.
- **Validate mode is the validation edge** (`pack-validation`): `PackCheck.validate` =
  `read.rationale().and(placement().check(...))`, mapped by `PackVerdicts`; the placement rules (configured level,
  org fragment) and `PlacementCodes` are its own (S2). The service runs no `pack-validation` main code.
- **One code and one wording per fault (R2).** The converters, `PackPolicy`, `PackFinding` and `PackFindingCode` are
  deleted; every surface states kernel `Reason`s, each token built once (`PackCodes`, `StorageCodes`,
  `PlacementCodes`). The changed answers are listed in the R2 table and the `### Breaking` fragments.
- **An unmodelled file is not held (Q1).** A `file_not_held` warning, removed before storing; validate mode judges
  nothing in a file not held (open case 6).
- **Registration answers every fault (S8)** of a pack whose `pack.yaml` is missing or unreadable.
- **Tests per rule, per composition and per mapper,** in their subject's module; every code has a failing and a
  passing fixture (`PackCodesCoverageTest`, `PlacementCodesCoverageTest`); the golden snapshot holds apart from the
  enumerated diff list of NFR-002.
- **Mutation margins** re-set from the measurement (ADR-0062, amendment of 2026-11-17).
